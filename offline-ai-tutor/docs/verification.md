# 当前验证范围

本项目为依据需求重新实现的初版；不能把旧整机报告中的实测值直接视作本版本结果。

## 本地检查

使用标准库 unittest 启动实际本地 HTTP 模拟模型，检查：

- 页面和静态资源返回、本地请求限制、跨域阻断和路径访问边界。
- 输入长度、对话历史角色、上传编码与格式验证。
- 问答事件流、完成标志、并发限制和模型未配置状态。
- Ollama 逐行响应解析、可见输出与思考字段分离、速度计算。
- 人工复核标记筛选、题目去重、确定性划分及四步字段校验。
- LoRA 训练配置、规范化题目去重、dry-run 状态、实际子进程日志及失败产物识别。

具体执行命令、环境版本和最新结果记录在 `local-checks.md`。
自动检查使用模拟上游，不代表真实模型的推理效果。
训练进程检查使用明确标注的模拟可执行文件；当前没有 GPU 训练结果。

## 尚需目标设备验证

1. 实际模型是否正确导入，标签、摘要、基础模型和适配器能否对应。
2. ARM 依赖兼容性、OCR 模型加载、断网识别及置信度输出。
3. 摄像头节点、预热参数、图像颜色和现场光照。
4. 图形桌面、自启服务和屏幕休眠处理。
5. 微调前后及量化前后的答案正确性、讲解质量和性能。
6. 实际资源清单、数据来源和许可披露。

仓库不包含伪造的训练结果、硬件测试数字或历史提交记录。
