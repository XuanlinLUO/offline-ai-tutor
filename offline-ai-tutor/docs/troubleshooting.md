# 故障排查

| 现象 | 检查与处理 |
|---|---|
| 页面提示模型未配置 | 设置 `.env` 中 `OLLAMA_MODEL`，重新启动服务 |
| 模型未安装 | 对照 `ollama list`，标签必须匹配；自定义模型需先实际导入 |
| Ollama 无法连接 | 检查本机服务与端口；本项目不接受远程 Ollama 地址 |
| 有思考但没有可见解答 | 查看模型能力、思考模式和输出上限，不把空回答当成功 |
| 生成中断 | 页面会提示未完成，检查模型日志、内存和超时，不记录为正确完成 |
| 摄像头无法打开 | 核对设备节点、V4L2 输出和用户权限；先用系统工具验证采集 |
| 前几帧过亮或偏色 | 比较预热帧配置与拍摄效果，调整光照，记录真实改善情况 |
| OCR 缺依赖 | 安装目标 ARM 环境兼容的 PaddlePaddle、PaddleOCR 和 OpenCV |
| OCR 第一次很慢 | 提前准备模型缓存，分别测量冷启动与热运行 |
| OCR 异常崩溃 | 保留系统日志与依赖版本，尝试降低线程数；尚未证明统一根因 |
| 屏幕空闲后无信号 | 区分服务异常与显示休眠；X11 场景检查 DPMS 和屏保 |
| 后端启动但没有全屏页面 | 检查图形会话是否登录、桌面 autostart 是否执行 |
| 上传图片不准确 | 拍正、减少阴影、核对数字和公式；当前为通用文本 OCR |

后端日志不记录题目正文，错误堆栈仍可能包含本机路径。向外提供日志前检查内容。
服务管理命令：

```bash
systemctl --user status ai-tutor.service
systemctl --user restart ai-tutor.service
journalctl --user -u ai-tutor.service -f
```
